# dino game

A dino game with onekey and an LCD display

[demo](https://cdn.hackclub.com/01a156c1-c090-7db8-8c1f-4b98d3bdbec0/dino%20game%20demo.mov)

## What it does

click the button to start, and then you are playing the classic dino game from Google! your score will be at the top right.

## Parts list

| Part | Qty | Notes |
|------|-----|-------|
| ESP32 dev board | 1 | |
| Breadboard | 1 | Full size or half size |
| Jumper wires | 19 | Male to male |
| Push button | 1 | |
| LCD Display | 1 | 16x2 |
